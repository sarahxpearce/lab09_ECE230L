## Lab Questions
Summary: 

### In plain English describe the function and use of a multiplexer.
A multiplexor is a selector switch that lets you take multiple inputs and and lets you choose one to send to the output. It basically decides which of the input signals gets through to the output. 

### In plain English describe the function and use of a demultiplexer.
A demultiplexer is the opposite of a multiplexer. It takes one input and sends it to one of multiple outputs. It's like deciding which device gets the signal. 

### What other uses might these circuits have? (Think Shannon’s)
I think that using multiplexers and demultiplexers would be useful in any situation where you need to control where data goes (without needing a ton of extra wiring). I think that CPU's would be a good example of somewhere where they would be helpful.
